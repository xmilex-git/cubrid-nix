# (the default since ADR 0017 D9), and only there: a --by-category run and CI
# keep them. One scenario-relative entry per line (CTP containPath semantics,
# like CTP's exclusions.txt), # comments. The runner adds these to the suite's
# default list; a custom EXCLUDE=<file> replaces both, and EXCLUDE='' drops both.

# A case belongs here when a dir split makes it fail for a reason that is not
# the change under test, and no cheap colocation undoes that. Two kinds so far:
#   - its answer was recorded against CI's whole serial order;
#   - a known engine defect the split's placement triggers (with its issue).
# Each entry says which, and when it can go.
