# Banner artwork

`banner.png` was composed with GPT Image Gen using these reference marks:

- **CUBRID:** the colored symbol from the [official website logo](https://www.cubrid.org/layouts/layout_master/img/cubrid_logo.jpg), with the wordmark omitted.
- **Nix:** the [Nix Snowflake](https://github.com/NixOS/nixos-artwork/tree/master/logo), originally designed by Simon Frankau and revised by Tim Cuthbertson. The source artwork is published under [CC-BY](https://github.com/NixOS/nixos-artwork/blob/master/logo/README.md#license). The wordmark is omitted in the banner.
- **Cloud computing:** Google's [Material Design cloud icon](https://github.com/google/material-design-icons/blob/master/png/file/cloud/materialicons/48dp/2x/baseline_cloud_black_48dp.png), published under the [Apache License 2.0](https://github.com/google/material-design-icons/blob/master/LICENSE).

The composition is decorative. It represents the project's tools and target
environments rather than a deployment architecture.
